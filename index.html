ChurnAI — Customer Intelligence Platform

A fully interactive dashboard that models customer churn risk for a subscription-style business. Includes a live customer database with search and filters, an interactive churn risk calculator with personalised retention recommendations, and a model evaluation page with confusion matrix and feature importance charts. Fully multilingual (English, Japanese, Mandarin, German, French, Spanish). All data is synthetically generated for demonstration purposes and refreshes daily at 00:00 JST.

Document Intelligence · In-Browser AI

BriefAI — Document Intelligence

A single-file, in-browser PDF summariser. Upload a PDF and get back a structured summary plus keywords — entirely client-side, with no backend, no account, and no API key required. Detects the document's language (English, Japanese, Chinese, German, Spanish, French, Dutch) and scores every sentence by word frequency to extract the most important ones, keeping the summary in the document's own language. Because everything runs locally in the browser, the file never leaves the user's device.
